## Suggested structure (template)

| Segment | Suggested content | Source |
|---------|-------------------|--------|
| Intro | Product, organization, milestone | Project metadata |
| The pilot | Who took part (anonymized groups), what was done | Pilot results |
| Results | Wallet setup, issuance and verification rates | Issuance register (calculated) |
| Feedback | Satisfaction and key themes | Feedback analysis |
| Improvements | Three+ key improvement areas | Improvement plan |
| What's next | Scaling and adoption direction | Scaling / roadmap |
| Close | Links to this evidence repository | README |
