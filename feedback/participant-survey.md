# Participant Survey Instrument

> **Status:** 🟡 **Actual administered instrument.** The questions below are those actually used
> in the participant (student) feedback form, reconstructed from the response export. Only
> anonymized results are published; the form did not collect names or emails.

**Audience:** Pilot participants (students and IT talents).
**Purpose:** Capture completion of each step, satisfaction, issues, and suggestions.
**Consent gate:** responses were only used where the participant agreed their anonymous
feedback could be included in the pilot report.

## Questions

| # | Question | Response type |
|---|----------|---------------|
| 1 | Do you agree that your anonymous feedback may be used in the pilot report? | Yes / No |
| 2 | How did you complete each step? — Install and set up the wallet | Easily / With help / Not completed / Not attempted |
| 3 | How did you complete each step? — Receive the credential | Easily / With help / Not completed / Not attempted |
| 4 | How did you complete each step? — Verify or present the credential | Easily / With help / Not completed / Not attempted |
| 5 | How satisfied were you with the logistics? (Accommodation, Welcome kit, Communication emails, Transportation, Welcome activity, Venue, Activities, Closing ceremony) | 1–5 each *(event logistics — reported separately from product feedback)* |
| 6 | Which problems did you experience? | Multi-select / open (anonymized) |
| 7 | How satisfied are you with the overall experience? | 1–5 |
| 8 | How useful is a digitally verifiable credential to you? | Very useful / Useful / Not sure |
| 9 | Would you use FairWallet again? | Yes / Maybe / No |
| 10 | What is the one most important improvement we should make? | Open (anonymized) |
| 11 | Any additional comment? | Open (anonymized) |

_Results and denominators are in [feedback-analysis.md](feedback-analysis.md)._
